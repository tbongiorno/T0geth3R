# Together — shallow Expo prototype

A UI-first React Native + Expo reconstruction of the supplied Figma boards.

### Included
- Auth flow: splash, login, create account, interests, profile
- Home/map-style screen
- Settings
- Friends/discovery/friends list
- Groups/create/detail
- Events/all/upcoming/past/create
- Static local prototype data and cropped reference assets
- State-based navigation to keep the prototype intentionally shallow

### Run
```bash
npm install
npx expo start
```
Press `w` for web or run on an Expo-supported simulator/device.

This intentionally does **not** include a backend, real authentication, database, API layer, or production navigation architecture.
